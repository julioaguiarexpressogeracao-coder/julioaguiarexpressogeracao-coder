## Sobre mim

Sou Júlio Aguiar, atuo com TI na Expresso Geração e estudo **Ciência de Dados na Universidade Federal do Ceará (UFC)**.

Meu trabalho conecta desenvolvimento de software às necessidades da operação: organizar informações, automatizar rotinas e construir ferramentas para apoiar as equipes. Nesta conta, reúno projetos voltados à logística, à gestão de recursos e à integração entre sistemas.

## Soluções que fazem parte deste perfil

| Projeto | Propósito | Tecnologias |
| :--- | :--- | :--- |
| **Operação Mercosul** | Gestão de viagens rodoviárias internacionais, com acompanhamento da frota, etapas operacionais e integração com rastreamento. | Next.js · React · Supabase · Tailwind CSS |
| **Itinerário Geração** | Planejamento de rotas e apoio à programação de paradas, pernoites e abastecimento em viagens de carga. | React · TypeScript · TanStack · Leaflet · Supabase |
| **Middleware Raster** | Integração entre o planejador de viagens e a API Raster, com tratamento de dados de viagens e rotas. | Node.js · TypeScript · Vercel |
| **Controle de Equipamentos** | Gestão de dispositivos e responsáveis, com histórico de entregas, devoluções e transferências, além de termos de movimentação. | Next.js · React · Prisma · PostgreSQL |
| **Controle de Avarias** | Registro e acompanhamento de avarias de carga, estoque, vendas e indicadores, com exportação para planilhas. | Next.js · TypeScript · Prisma · PostgreSQL · Recharts · ExcelJS |
| **Chamados Internos** | Organização de solicitações entre setores, com acompanhamento de filas, atualizações em tempo real e notificações. | Next.js · React · Supabase · ECharts · Nodemailer |

> Os repositórios dos sistemas corporativos são privados. Esta página apresenta uma visão geral dos projetos.

## Foco do meu trabalho

- **Digitalizar processos:** transformar controles dispersos em aplicações organizadas.
- **Conectar sistemas:** integrar dados operacionais e reduzir tarefas manuais.
- **Dar visibilidade à operação:** apresentar informações por meio de mapas, painéis e relatórios.
- **Manter a rastreabilidade:** registrar movimentações, etapas e históricos para facilitar o acompanhamento.
